# Nebulix.dev

Zamonaviy, futuristik va neon uslubidagi shaxsiy portfolio sayti. Loyiha
HTML, CSS va JavaScript yordamida yaratilgan.

## ✨ Imkoniyatlar

-   Qoramtir dizayn, neon aksentlar va animatsiyalar.
-   Desktop va mobil ekranlarga moslashuvchi responsive layout.
-   Kunduzgi va tungi rejim; tanlangan tema brauzerda saqlanadi.
-   Interaktiv navigatsiya, loyiha kartalari va kontakt bo'limi.
-   HTML, CSS va JavaScript kodlari alohida fayllarda.

## 📁 Fayl tuzilishi

``` text
nebulix-source/
├── index.html   # Sahifa tuzilishi va kontent
├── style.css    # Dizayn, animatsiyalar va responsive qoidalar
├── script.js    # Interaktivlik va tema boshqaruvi
└── README.md    # Loyiha haqida ma’lumot
```

## 🚀 Ishga tushirish

1.  `index.html`, `style.css`, `script.js` va `README.md` fayllarini
    bitta papkada saqlang.
2.  `index.html` faylini brauzerda oching.
3.  Matnlarni `index.html` dan, dizaynni `style.css` dan, interaktiv
    funksiyalarni esa `script.js` dan tahrirlang.

Oddiy holatda ishga tushirish uchun build vositasi yoki paket o'rnatish
talab qilinmaydi.

## 🎨 Moslashtirish

-   Loyiha nomlari, matnlar va havolalarni `index.html` ichida
    yangilang.
-   Kontakt bo'limidagi email manzilini haqiqiy manzilingiz bilan
    almashtiring.
-   Ranglar, shriftlar va neon effektlarini `style.css` orqali sozlang.
-   JavaScript funksiyalarini `script.js` ichida kengaytiring.

## 🌐 Texnologiyalar

-   **HTML5** --- sahifa tuzilishi
-   **CSS3** --- dizayn, animatsiyalar va responsive ko'rinish
-   **JavaScript** --- interaktivlik va kunduzgi/tungi rejim
